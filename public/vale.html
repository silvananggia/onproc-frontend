Kebijakan Privasi Aplikasi VALE

Terakhir diperbarui: 19 Februari 2026

Aplikasi VALE (Variabilitas Aliran untuk Lokasi Embung) dikembangkan oleh Pusat Riset Geoinformatika (PRGI) BRIN bekerja sama dengan Dinas Sumber Daya Air Provinsi Jawa Barat. Kami berkomitmen untuk melindungi privasi pengguna kami.

1. Informasi yang Kami Kumpulkan

Informasi Lokasi: VALE meminta akses ke lokasi GPS perangkat Anda (ACCESS_FINE_LOCATION dan ACCESS_COARSE_LOCATION). Informasi ini hanya digunakan untuk menampilkan posisi Anda di peta interaktif terhadap data sungai dan embung.

2. Penggunaan Data

  • Data lokasi diproses secara lokal di perangkat Anda (ephemeral).
  • Kami tidak menyimpan riwayat lokasi Anda di server kami.
  • Kami tidak membagikan data lokasi Anda kepada pihak ketiga atau pengiklan.

3. Keamanan

Kami melakukan langkah-langkah teknis yang wajar untuk memastikan data yang diproses melalui aplikasi tetap aman. Karena kami tidak mengumpulkan data pribadi (seperti nama atau nomor telepon) di server pusat, risiko kebocoran data pribadi sangat minim.

4. Persetujuan Pengguna

Dengan menggunakan aplikasi VALE, Anda menyetujui pengumpulan dan penggunaan informasi sesuai dengan kebijakan ini. Anda dapat mencabut izin lokasi kapan saja melalui pengaturan perangkat Anda.

5. Kontak Kami

Jika Anda memiliki pertanyaan tentang kebijakan privasi ini, silakan hubungi kami di:

Email: prgi@brin.go.id atau dissda@jabarprov.go.id
